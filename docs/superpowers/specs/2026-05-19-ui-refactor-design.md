# UI Refactor Design: 双栏文件管理器风格

## 目标

重构 Pegasus Game Filter 的 UI，解决当前"操作复杂、概念难理解、功能不专一"的问题。核心思路：**去掉视图切换和任务队列，改为双栏文件管理器风格的即时操作。**

## 当前问题

1. **来源/项目双视图 + 任务队列**：用户需理解视图切换 → 选中游戏 → 添加到任务队列 → 确认执行，三步流程中每个环节都有独立概念
2. **MainWindow 超载**：1134 行，项目管理、主题/语言切换、视图切换、任务管理、元数据编辑、批量操作、游戏启动全集中在一起
3. **工具栏混乱**：8 个按钮根据视图条件显隐，execute_btn 在不同视图下行为不同（复制 vs 删除）
4. **分页浏览**：每页 200 条游戏需用翻页按钮浏览

## 核心使用场景

从大量 ROM 来源中**挑选**游戏，复制到精选收藏集。

## 整体布局

```
┌─────────────────────────────────────────────────────────┐
│  菜单栏: 文件 | 工具 | 设置(语言/主题) | 帮助               │
├────────────────────┬──────────┬──────────────────────────┤
│  来源 ROM (左侧)    │  操作区   │  收藏 ROM (右侧)          │
│  ───────────────── │          │  ─────────────────────── │
│  [搜索...       ]  │  [→ 复制] │  [搜索...              ]  │
│  [平台: 全部 ▾  ]  │  [← 删除] │  [平台: 全部 ▾         ]  │
│                    │          │                          │
│  ┌────────────────┐│          │  ┌──────────────────────┐│
│  │ 游戏列表       ││          │  │ 游戏列表              ││
│  │ 无限滚动       ││          │  │ 无限滚动              ││
│  └────────────────┘│          │  └──────────────────────┘│
│  共 N 个           │          │  共 M 个                  │
├────────────────────┴──────────┴──────────────────────────┤
│  预览面板 (可折叠)                                        │
│  [封面] [视频]  |  名称/平台/开发者/描述  [编辑] [运行]     │
└──────────────────────────────────────────────────────────┘
```

### 关键变化

- 去掉视图切换 — 来源和收藏同时可见
- 去掉任务队列概念 — 中间只有"复制"和"删除"两个方向按钮
- 去掉工具栏按钮显隐 — 操作始终在同一位置
- 分页 → 无限滚动
- 预览区下置为可折叠面板

## 核心操作流程

### 复制（来源 → 收藏）

1. 左侧选中一个或多个 ROM（Ctrl+Click / Shift+Click / Space 勾选）
2. 点击 `→ 复制` 按钮，或拖拽到右侧面板，或按 `F5`
3. 立即执行文件复制：ROM + 封面 + logo + 视频 → 收藏目录
4. 右侧面板即时刷新
5. 状态栏显示结果："已复制 N 个游戏"

### 删除（从收藏）

1. 右侧选中一个或多个游戏
2. 点击 `← 删除` 按钮或按 `Del`
3. 确认对话框
4. 立即执行删除（ROM 文件 + media 目录）
5. 右侧面板即时刷新

## 面板功能

### 来源面板

| 功能 | 行为 |
|------|------|
| 搜索 | 实时过滤（名称/平台/开发者） |
| 平台过滤 | 下拉选择，默认"全部" |
| 无限滚动 | 每批加载 200，触底自动加载 |
| 已存在标记 | 收藏中已有的游戏灰色斜体 + 不可重复复制 |
| 文件缺失标记 | ROM 缺失的游戏红色 + ⚠ 图标 |
| 选择 | 单击 / Ctrl+Click / Shift+Click / Space |
| 键盘 | J/K 上下移动，Enter 预览，F5 复制 |

### 收藏面板

| 功能 | 行为 |
|------|------|
| 搜索 | 同来源面板 |
| 平台过滤 | 同来源面板 |
| 无限滚动 | 同来源面板 |
| 编辑标记 | 元数据修改过的游戏 ✎ 图标 |
| 文件缺失标记 | 同来源面板 |
| 键盘 | J/K 移动，Enter 预览，Del 删除 |

### 快捷键

| 键 | 作用 |
|----|------|
| J / K | 上下移动选择 |
| Space | 勾选/取消勾选 |
| F5 | 复制选中 → 收藏 |
| Del | 删除选中（收藏面板） |
| Ctrl+F | 聚焦搜索框 |
| Ctrl+P | 聚焦平台下拉 |
| Enter | 展开预览 / 播放视频 |
| Tab | 左右面板间切换焦点 |

## 预览面板

底部可折叠面板，Enter 或双击展开，再次点击折叠。

```
┌──────────────────────────────────────────────────────────┐
│  封面(300px)  │  名称/平台/开发者/文件/描述                │
│               │  视频播放区域 (点击播放/暂停)               │
│               │  [编辑元数据] [运行游戏]                   │
└──────────────────────────────────────────────────────────┘
```

- 收藏面板中字段可编辑，来源面板中只读
- `[编辑元数据]` → MetadataEditDialog
- `[运行游戏]` 依赖平台 Header 的 launch 配置

## 保留的辅助功能

全部保留，整合进新布局：

- 项目管理：菜单栏 `文件 → 新建/打开/保存/最近打开`
- 元数据提取/合并：菜单栏 `工具 → 提取元数据/合并元数据`
- 语言切换：菜单栏 `设置 → 语言 → 简体中文/English`
- 主题切换：菜单栏 `设置 → 主题 → Light/Dark/Blue/Sepia`
- 批量添加：右击菜单或输入关键词批量搜索匹配
- 启动对话框：程序启动时显示

## 架构变化

### 删除 / 合并

| 当前 | 处理后 |
|------|--------|
| `MainWindow` 中的视图切换逻辑 (~200 行) | 移除，两侧面板独立 |
| `TaskQueue` / `Task` / `TaskType` / `TaskStatus` | 移除，改用直接操作 |
| `LogWindow`（任务执行日志） | 合并到状态栏实时反馈 |
| 工具栏 8 按钮显隐逻辑 | 移除，中间固定 2 按钮 |
| `select_all_btn` 仅在项目视图可见 | 两侧面板都有自己的全选 |
| 分页组件 `pagination_label` / `prev_page_btn` / `next_page_btn` | 移除，改为无限滚动 |

### 保留

- `GameManager` — 添加直接执行的 add_game / remove_game 方法
- `GameListWidget` — 重构为左右两个独立面板实例
- `GameDetailWidget` — 移至底部可折叠预览面板
- `MetadataParser` — 不变
- `Project` — 不变
- `i18n` / `theme` — 不变
- 所有对话框：`MetadataEditDialog`, `MetadataExtractDialog`, `MetadataMergeDialog`, `AboutDialog`, `StartupDialog`, `ProjectSettingsDialog`

### 新增

- `DualPanelLayout` — 双栏布局容器（QSplitter）
- `SourcePanel(ASourcePanel)` — 来源面板（封装 GameListWidget + 搜索/平台过滤 + 无限滚动）
- `CollectionPanel(CollectionPanel)` — 收藏面板（同上，增加删除能力）
- `OperateBar` — 中间操作区（复制/删除按钮）
- `PreviewPanel` — 底部可折叠预览面板
- `InfiniteScrollList` — 无限滚动列表 mixin/组件
